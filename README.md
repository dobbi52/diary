# 우리들의 교환일기

다른 학교 학생과 일기를 주고받는 도구입니다. 일기는 자동 필터와 교사 승인을 거친 뒤 쪽지 뽑기로 배달됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `Code.gs` | 서버 (구글 시트 + Apps Script) |
| `index.html` | 학생 화면 |
| `teacher.html` | 교사 화면 (생각 오락실 로그인) |
| `config.js` | 서버 주소 한 줄 |

## 올리는 순서

1. **구글 시트 만들기**: https://sheets.new 에서 새 시트를 만들고 이름을 `교환일기 서버`로 바꿉니다.
2. **서버 붙이기**: 시트 메뉴 `확장 프로그램 → Apps Script`를 열고, 기본 코드를 지운 뒤 `Code.gs` 내용을 붙여 넣고 저장합니다.
3. **처음 설정**: 위쪽 함수 선택에서 `setup`을 고르고 `실행`을 누릅니다. 권한 요청이 뜨면 허용합니다.
   - 실행 로그에 나오는 **교사 초대 코드**(6자리)를 적어 둡니다. 다른 선생님께 이 코드를 알려 주면 됩니다.
   - 시트에 Teachers, Rooms, Students, Diaries, Tickets, Draws 탭이 생깁니다.
4. **배포**: `배포 → 새 배포 → 유형: 웹 앱`, 실행 계정 `나`, 액세스 `모든 사용자`로 배포하고 `…/exec`로 끝나는 주소를 복사합니다.
5. **주소 넣기**: `config.js`의 `여기에_배포_주소`를 복사한 주소로 바꿉니다.
6. **GitHub에 올리기**: https://github.com/new 에서 저장소 `diary`를 만들고 네 파일(`Code.gs` 빼고 올려도 됨)을 올립니다. `Settings → Pages`에서 `main` 브랜치를 켭니다.

## 처음 쓰는 법 (교사)

1. 교사 화면에서 생각 오락실 계정으로 로그인 → 교사 초대 코드 입력 (처음 한 번)
2. 방 만들기: 반 이름과 학생 수를 넣으면 1번부터 번호가 만들어집니다. 학생 이름은 받지 않습니다.
3. 학생은 방 코드(5자리)를 넣고 자기 출석 번호를 누른 뒤, 처음 한 번 비밀번호 숫자 4자리와 필명을 정합니다.
   - 비밀번호를 5번 틀리면 그 번호만 10분 동안 잠깁니다.
   - 잊어버리면 학생 명단 탭에서 비밀번호 초기화 → 학생이 새로 정합니다. 일기 기록은 그대로입니다.
4. 원하면 학생 명단 탭에서 이름을 붙일 수 있습니다. 이름은 서버로 보내지 않고 그 기기 브라우저에만 저장되어 "3번 김가나"처럼 보입니다.

## 정해 둔 규칙 (Code.gs 맨 위에서 바꿀 수 있어요)

- 일주일(월요일 시작) 2편, 반려된 일기는 편수에 들어가지 않음
- 승인되면 뽑기권 1장, 기한 7일
- 일기 한 편은 최대 2명이 뽑음, 덜 읽힌 일기부터 나옴, 같은 반 일기는 안 나옴
- 뽑은 일기는 7일 동안 보임
- 글자 수 기본 150~800자 (방마다 설정에서 바꿈)
- 바로 막는 것: 전화번호, 이메일, 인터넷 주소, @아이디, 욕설
- 교사에게 표시만 하는 것: 학교·동네·SNS 관련 말, 영어 아이디처럼 보이는 말, 마음을 살펴볼 말(빨간 표시)

## 초대 코드 바꾸기

Apps Script에서 `setInviteCode` 함수의 따옴표 안을 새 코드로 고치고 실행합니다.

## Code.gs를 고친 뒤

`배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포`로 같은 주소를 유지한 채 바꿉니다.
